# Nostra – E-Commerce Website

Nostra is a modern and responsive fashion e-commerce website designed to provide a smooth and stylish shopping experience.

## 🚀 Features

* Responsive and modern UI
* Home, Collections and Contact Us pages
* Product search functionality
* Product filtering by:

  * Occasion
  * Color
  * Ideal For
* Wishlist functionality
* Mobile responsive navigation
* Special offers and promotional sections
* Newsletter subscription section
* Contact form
* Modern hover effects and animations

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Font Awesome
* Google Fonts
* Unsplash Images

## 💻 Pages

### Home

The home page includes a hero section, services, seasonal offer banner and newsletter subscription.

### Collections

The collections page displays products with search and filtering options for occasion, color and target audience.

### Contact Us

The contact page provides contact information along with a form to send a message.

## 📱 Responsive Design

The website is optimized for desktop, tablet and mobile devices with a responsive navigation menu, mobile filters and responsive product grids.

## 🔍 Product Features

Products are dynamically loaded using JavaScript, with product name, occasion, color, ideal audience, price and image data.

The collection page supports real-time search and multiple filters to help users find products easily.
